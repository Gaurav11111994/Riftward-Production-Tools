# Riftward Reference Learning Bank

This file records the **deduplicated learning categories** extracted from the user's supplied reference assets. It is intentionally about transferable craft knowledge, not object-for-object copying.

## Deduplication policy

Duplicate copies are ignored. Multiple different assets teaching the same technique may still be useful.

## Usage rule

Do not select a reference because its object name matches a Riftward object.

Select it because it teaches a useful **construction, surface, material, UV, lighting, damage, or readability principle**.

The reference bank exists to improve original Riftward art, not to substitute third-party identity for Riftward design.
