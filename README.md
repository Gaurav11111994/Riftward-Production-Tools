# Riftward Production Tools

Reusable production guidance and AI/Codex skills for the **Riftward** environment-production pipeline.

## Included

- `SKILL.md` — master Blender production + hero-refinement skill.
- `references/REFERENCE_BANK.md` — deduplicated learning/reference bank and transferable lessons.
- `manifest.json` — package metadata.

## Core principle

**Riftward references define WHAT to build. The learning assets teach HOW to build and polish it.**

The supplied commercial/reference assets are used as craft references for modeling, topology, UVs, materials, weathering, fracture, lighting, surface response and detail hierarchy. They are not copied object-for-object.

## Blender / Unity boundary

**Blender owns:** geometry, silhouettes, structural detail, faceting, semantic material regions, rough source lookdev, LOD-ready source geometry, production-safe transforms/pivots.

**Unity later owns:** final URP/PBR response, reflections, transparent/glass/ice behavior, portal energy, atmosphere, particles, motion, color grading and runtime lighting.
